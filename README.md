# Expo Chat App

A real-time chat application built with Expo and React Native. The app provides a modern messaging experience with user authentication, one-to-one conversations, message history, responsive UI, and seamless navigation. Designed with reusable components, clean architecture, and scalable state management for Android and iOS platforms.

## Features

* User Authentication (Login/Signup)
* Real-time Messaging
* Chat List & Conversation Screen
* Message Timestamps
* Responsive & Modern UI
* Navigation with Expo Router / React Navigation
* State Management
* API Integration
* Cross-Platform Support (Android & iOS)
* Clean & Scalable Project Structure

## Tech Stack

* React Native
* Expo
* TypeScript / JavaScript
* React Navigation / Expo Router
* Context API / Redux
* Firebase / REST API
* AsyncStorage

## Installation

```bash
git clone <repository-url>

cd expo-chat-app

npm install

npx expo start
```

1. Install dependencies.
2. Configure environment variables.
3. Start the Expo development server.
4. Run the app on Android, iOS, or Expo Go.
